# 09 — Glosario técnico

| Término | Significado en HUC |
|---|---|
| ESP / BES | Bomba electrosumergible |
| PIP | Pump Intake Pressure; en BES a menudo en ft de fluido según hoja |
| THD | Total Dynamic Head / altura total de descarga |
| BFPD / BWPD / BOPD | Caudales fluido / agua / petróleo por día |
| RC-BES | Regla candidata del expediente BES (no aprobada operacionalmente) |
| Expediente | Dataset bajo `datasets/en_uso/<id>` |
| Valores en uso | Ajustes temporales de simulación en memoria Data |
| Contrato v1 | JSON estructurado del asistente |
| Espejo codigo/ | Copia de fuentes dentro de `HUC-1.0.0` para build Docker |
| SDD / Spec Kit | Spec-Driven Development con GitHub Spec Kit |
