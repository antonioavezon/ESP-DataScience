HUC 1.0.0
Linux x86-64, Docker y Docker Compose.
Memoria recomendada: 8 GiB o más si se usa el modelo lingüístico.
Perfil CPU: ./instalar.sh y ./iniciar.sh
Perfil GPU NVIDIA: ./iniciar.sh gpu
El archivo .env guarda la clave del simulador y los hosts permitidos.
No hace falta Python ni Django en el anfitrión.
Los puertos publicados son 8000 y 8001.
MQTT y Ollama permanecen en la red interna huc.
